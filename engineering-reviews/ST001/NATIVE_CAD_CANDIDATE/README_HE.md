# ST-001 — מקור CAD חדש לסקירה

**DESIGN_ONLY / NO_CUT / NO_OCCUPANT_USE**

מועמד B-rep חדש המבוסס על מוצקי FreeCAD של R18-A-FIX ועל בחירת החלקים, הקיבוץ וההזזות שתועדו בתצוגת R21. הוא משמש בסיס לסקירת 16 ממשקי מסילה–רגל. ההתאמה ל־R30 ולגאומטריית B21 שלו נשארת פתוחה.

- [מקור FreeCAD לעריכה](ST001_NATIVE_CAD_CANDIDATE_DESIGN_ONLY.FCStd)
- [STEP לתוכנות CAD אחרות](ST001_NATIVE_CAD_CANDIDATE_DESIGN_ONLY.step)
- [דוח QA ומיפוי מקורות לכל מוצק](QA.json)
- [קוד לשחזור](build_candidate.py)

## תכולה והחלטות

- 68 פריטי B-rep יחידים ממשפחות A01, A02, A03, A04 ו־C01, וארבע קבוצות מסילה עליונה. כל קבוצה כוללת שלושה מוצקים נפרדים של B01 ו־E01. יחד 72 פריטי FreeCAD ו־80 מוצקים. קבוצות המסילה שומרות שמות R21 כדי שאפשר יהיה לאמת את מקורן מול התצוגה.
- הגופים נלקחו ישירות מה־FCStd המקובע של R18. קובץ R21 שימש לזיהוי המופעים הפעילים ולהעברת ההזזות בלבד. התסריט אימת שמערכי הגאומטריה והנתונים הבינאריים של GLB זהים בין R18 ל־R21. כל קבוצה מיוצגת כ־compound ובו שלושת המוצקים ללא איחוד.
- בהתאם לסצנת R21, המועמד כולל שמונה שכבות E01 שהוצגו ומותיר מחוץ לסצנה שמונה שכבות E01 נוספות ו־16 מצייני מקום של F01. רשימת ההחרגות המלאה ב־JSON.
- יחידות CAD הן מ״מ וציר Z אנכי. הקוד ממיר הזזות מהצירים של GLB ‏`(X, Z, -Y)` ומהיחידות במטרים. גרסאות המקור והגיבובים רשומים בדוח.

## תוצאות הבדיקה הדיגיטלית

| בדיקה | תוצאה |
|---|---|
| FCStd בקריאה חוזרת | 72 פריטים עם אותם שמות ומיפוי מקור, נפחים ומעטפות |
| STEP בקריאה חוזרת | 80/80 מוצקים סגורים, תקינים ובעלי נפח חיובי |
| חפיפות סטטיות | 3,160 זוגות במלאי. 500 זוגות עם תיבות חופפות או נוגעות נבדקו בחיתוך בוליאני. אפס חפיפות נפח מעל 0.00001 ממ״ק |
| ממשקי מסילה–רגל | 16/16 מגעי פאה נומינליים במועמד, 8 עליונים ו־8 תחתונים. בדוח נרשמו הזוגות בפועל ושטח הפאה המשותף |
| רצף הרכבה, תנועה, חומר וחוזק | NOT_RUN |

מגעי הפאה והחפיפות נבדקו במיקום הסטטי של המועמד. אישור התאמה ל־R30, אימות פיזי ושחרור ייצור נשארים חסומים.

## שחזור

נבדק עם FreeCAD 1.0.0 ו־OCCT 7.8.1. ב־Debian, מסביבת מאגר עם שני commits המקור זמינים:

```sh
git fetch origin review/st001-r21-visual-b8bfe12
PYTHONPATH=/usr/lib/freecad-python3/lib /usr/bin/python3 \
  engineering-reviews/ST001/NATIVE_CAD_CANDIDATE/build_candidate.py \
  --out /tmp/st001-native-cad
```

התסריט שומר זמנית את קובץ המקור בתיקיית הפלט ומפיק משם את שני קובצי ה־CAD וה־QA. בהרצה הראשונה הקריאה ל־`Part.makeCompound` נסגרה בתהליך ללא ממשק גרפי. המעבר ל־`Part.Compound` אפשר להריץ את הבנייה המלאה ולבדוק שוב את היצוא. בוצע תיקון תוכנה אחד ואפס תיקוני גאומטריה.
