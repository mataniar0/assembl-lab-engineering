# A_RIM_OPEN — DESIGN_ONLY

Recommended for lead review, NO_HOLE. Not selected by this study.

Six OPEN counterpart witnesses. Lower disk starts at r80.8, upper at r82.8; upper witness relief is mandatory.

Assembly: L → U → six OPEN radially inward100mm before wall/top closure.

P04L/P04U are separate Ø190×6 profiles, Z456..462 /480..486, freegap18, pitch24.
Each has six closed tongue holes plus six separate web interfaces. DXF CUT_* layers
contain closed cut loops; NOT_CUT_DIMENSIONS contains annotations. SVG/PNG physical1:1mm
(at96dpi forPNG), dimension JSON/provenance and connections-and-paths.json accompany them.

`actual-21-body-DESIGN_ONLY.glb` includes the19-body selected base plus two disks only.
`witness-*` are non-BOM interface reservations, not finished P05. Plans/sections and
core-and-layer-stack show these separately from skin/tool envelopes. Exploded views
are illustrative separation, not a substitute for continuous path evidence.

No positive tongue lock, strength, calibrated fit, physical assembly, nesting or cutting
approval. See project CTB-004 reports and ../../CTB-005-HANDOFF.md for open dependencies.
